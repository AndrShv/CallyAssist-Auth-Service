--------- Пояснение потоков данных ---------
Голосовой ввод → текст
Flutter-приложение передает голос.
Google Cloud Speech-to-Text преобразует в текст.
Опционально добавляется «Hey AI» для активации ассистента.
--------- NLP / AI ---------
Текст команды поступает в LLM (Gemini).
AI извлекает:
Действие (создать встречу, напоминание)
Участников (имена → Google Contacts)
Дата и время (для календаря)
Генерирует структурированный JSON с командой.
--------- Асинхронная обработка ---------
RabbitMQ ставит задачи в очередь.
Уменьшает зависимость интерфейса пользователя от длительных процессов (создание встречи, отправка уведомлений).
--------- Backend / Сервисы ---------
Spring Boot принимает команду.
Сохраняет данные в MySQL.
Кэширует повторы/напоминания в Redis.
Отправляет Email через spring-boot-starter-mail.
Планирует отправку SMS / Push через выбранный сервис.
Взаимодействует с Google/Apple Calendar через API.
--------- Календарь и уведомления ---------
Создаёт события в Google Calendar (или Apple Calendar).
Добавляет повторяющиеся напоминания (каждый вторник/четверг).
Отправляет уведомления на email/SMS/Push.
--------- Flutter-приложение ---------
Получает обновления и уведомления.
Может показывать список событий и напоминаний.
Работает на iOS и Android одновременно.
--------- Дополнительно ---------
Можно добавить логирование всех действий через Spring + ELK (опционально).
Безопасность: OAuth2 для Google и Apple API.
Асинхронные задачи: уведомления, email и SMS могут выполняться в отдельных микросервисах через RabbitMQ.
Расширяемость: новые действия можно добавлять через LLM → dispatcher → microservices.



# Если обобщить, твой “Hey Cally” проект будет работать так:

1) Пользователь отдаёт голосовую команду через Flutter (iOS/Android).
2) STT (Speech-to-Text) превращает голос в текст (Google Cloud STT).
3) NLP + AI (Gemini / LLM) извлекает сущности и намерения:
- кто участвует (имена → контакты)
- когда (дата/время → календарь)
- что делать (создать встречу, поставить напоминание)
4) Command Dispatcher / RabbitMQ управляет асинхронными задачами, чтобы всё шло гладко, даже если уведомления или напоминания идут параллельно.
5) Backend (Spring Boot + MySQL / Redis) обрабатывает команды:
- создаёт события в Google/Apple календарях
- рассылает Email / SMS / Push уведомления
6) Интеграция с Google и Apple API для календарей, контактов и аутентификации через OAuth2.

# То есть по сути Cally превращается в персонального ассистента, который сам планирует, напоминает и уведомляет, при этом работает голосом и на телефоне.



# а как он поймет кому отсыласть конкретно приглашение?!
1) Через голосовое указание
-------- Ты говоришь --------:
«Создай встречу с друзьями: Андреем, Катей и Серёжей»
AI парсит имена → ищет их контакты (номер телефона или email) в твоей адресной книге.

-------- Технологии --------:

# NLP (Gemini/ChatGPT) для извлечения имён из текста.
    Адресная книга телефона / Google Contacts API → связывает имя с email/телефоном.
2) Через заранее созданые группы
В приложении можно создать группы: «друзья», «семья», «коллеги».
Команда: «Создай встречу с друзьями»
AI автоматически берёт всех членов группы и рассылает приглашения.
3) Через email/телефон прямо в команде
-------- «Создай встречу с 123@gmail.com и 456@gmail.com» --------:
Удобно для одноразовых встреч.
# Возможность уточнения

Если AI не уверен:

«Я не нашёл Катю в контактах, это kate@gmail.com?»
Ты подтверждаешь → AI сохраняет на будущее.

# Важно: AI сам не будет угадывать, кому отправлять. Он берёт данные из твоей адресной книги или из команд, которые ты ему дал.
